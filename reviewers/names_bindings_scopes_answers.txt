1.

course: Nonlocal variable
year: Local variable
2. school, course, year
3. No. year is local to student() and cannot be accessed outside its function.
4. Local course inside student() hides course in department().
5. Clear scope rules protect data by limiting where code can change a variable. Keeping variables local stops one function from silently breaking another. Early type binding lets compilers catch errors before execution. This prevents crashes and makes testing easier. Good design ensures data exists only where needed.
