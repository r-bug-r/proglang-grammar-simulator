Plain-English Jargon Glossary

  • Terminal: A final code character (e.g. A, *, =). Cannot be expanded.
  • Non-Terminal: A placeholder in angle brackets <expr> that must be replaced.
  • Leftmost Rule: Always replace the very first placeholder on the left before touching others.
  • Sentential Form: The temporary mixed string at any single step.

Balanced Parentheses Simulator: S → (S)S | ε

Grammar Anatomy: S → ( S ) S | ε
• '(' and ')' are matching brackets.
• Inner S allows NESTING (parentheses inside).
• Outer S allows CHAINING (parentheses beside).
• ε (epsilon) is the STOP button (empty string "").

Why Parentheses Are Always Balanced

In this grammar, an opening bracket ( can never be created alone. It is introduced only as part of the pair ( S ).

Because every single expansion introduces exactly one ( and one ) simultaneously, unbalanced strings like )( or (() are mathematically impossible.

Exam Practice Questions

Q: Can S → (S)S | ε generate )(?

No. The grammar strictly outputs ( before ).

Q: What role does ε play?

It serves as the base case that terminates recursion by erasing non-terminals.

C-Style Declarations CFG

Formal Declaration Grammar: <Decl> → <Type> <VarList> ;
<Type> → int | float | char
<VarList> → id | id , <VarList>
Test Candidates:
VALID SYNTAX
Statement conforms to <Type> <VarList> ; with type float and variables y, z.

Step-by-Step Derivation Breakdown

Grammar Characteristics

  • Mandatory Semicolon: The terminal ; is locked at the end of every <Decl>. Omitting it causes an immediate syntax error.
  • Allowed Types: Strictly limited to int, float, and char. Types like double or string are rejected unless added to the grammar rule.
  • Comma Recursion: <VarList> → id , <VarList> ensures that every comma is immediately followed by another variable name.

Combinatorial Language Sizing Calculator

Grammar Hierarchy: <S> → <NP> <VP> (Sentence = Noun Phrase + Verb Phrase)
<NP> → <Det> <N> (Noun Phrase = Determiner + Noun)
<VP> → <V> <NP> (Verb Phrase = Verb + Noun Phrase)
e.g. "the", "a"
e.g. "dog", "cat"
e.g. "chased", "saw"

Step-by-Step Calculation (Multiplication Rule)

Step 1
Noun Phrase Combinations: |⟨NP⟩| = |⟨Det⟩| × |⟨N⟩| = 2 × 2 = 4
Step 2
Verb Phrase Combinations: |⟨VP⟩| = |⟨V⟩| × |⟨NP⟩| = 2 × 4 = 8
Step 3
Total Valid Sentences: |⟨S⟩| = |⟨NP⟩| × |⟨VP⟩| = 4 × 8 = 32 Sentences

Why Multiplication Rule Applies

Under the Fundamental Counting Principle, when an event consists of $k$ independent sequential choices, the total outcomes is the product of choices at each stage:

Total = Options1 × Options2 × ...

Because any subject noun phrase can be matched with any predicate verb phrase, the sets multiply directly.
